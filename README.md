# ✨ shy_xhaTodo

A full-stack productivity and task management application designed to help users organize tasks, habits, notes, and personal information in one place.

## 🚀 Features

- 🔐 User Registration & Login
- 🔑 JWT-based Authentication
- ✅ Create, Read, Update & Delete Tasks
- 📝 Notes Management
- 🔄 Habit Tracking
- 🔒 Password Vault
- 📊 Dashboard & Statistics
- 🔎 Task Search & Filtering
- 📅 Due Date & Priority Management
- 💾 Persistent MySQL Database
- 📱 Responsive Frontend

## 🛠️ Technologies Used

### Frontend
- HTML5
- CSS3
- JavaScript
- Bootstrap

### Backend
- Java
- Spring Boot
- Spring Security
- Spring Data JPA
- Hibernate
- REST APIs
- JWT

### Database
- MySQL

### Development Tools
- IntelliJ IDEA
- Git & GitHub
- Maven
- Postman

## 🏗️ Project Architecture

Frontend → REST API → Spring Boot → JPA/Hibernate → MySQL
