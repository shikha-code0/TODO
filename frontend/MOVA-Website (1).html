How MOVA Works

A full-stack AI pipeline that runs pose estimation in your browser and saves data to a real database.

1

Camera Permission & Feed

MOVA uses getUserMedia to access your camera. Live video feeds into a hidden element processed by MediaPipe Pose at ~30fps entirely on your device via WebAssembly.

2

MediaPipe Pose Estimation

Google's MediaPipe Pose WASM model detects 33 body landmarks per frame — head, shoulders, elbows, wrists, hips, knees, ankles and more. No data leaves your browser.

3

Skeleton Rendering

Landmarks are drawn on a canvas overlay. Joints are color-coded: green (good form), red (deviation), yellow (low confidence). All 33 connections rendered with gradient lines every frame.

4

Joint Angle Calculation

3-point vector math computes angles at knees, hips and torso every frame using the live landmark coordinates.

5

Squat Phase State Machine

A state machine tracks hip Y-position across frames: Standing → Descend → Bottom → Ascend. A complete cycle = 1 counted rep.

6

REST API + SQLite Database

When you end a session, results are POST'd to /api/sessions (Node.js + Express). Your data is stored in SQLite with full rep-level detail and retrieved for the progress dashboard.

7

User Authentication

Register with email + password (bcrypt hashed). Login returns a JWT stored in localStorage. All API calls include the Bearer token for secure, per-user data.

Technology Stack

MediaPipe Pose

Google WASM pose estimation. 33 landmarks, ~30fps in-browser.

Node.js + Express

REST API server. Auth, session and user routes.

SQLite

Zero-config file database. Auto-created on first run.

JWT + bcrypt

Secure user authentication and password hashing.

HTML5 Canvas

GPU-accelerated skeleton overlay on video.

Vanilla JS

No frameworks. Pure JS for everything.

Safety & Responsible AI

MOVA operates with clear, transparent boundaries. AI in health must know what it cannot do.

🔍 What MOVA Can Do

Observe movement, calculate joint angles, detect movement phases, count reps and provide simple descriptive observations about what is detected in the current frame.

🚫 What MOVA Cannot Do

MOVA cannot diagnose injuries, pain, medical conditions or structural limitations. It cannot replace a physiotherapist, doctor, personal trainer or any qualified health professional.

🟡 Uncertainty Handling

When confidence drops below threshold, MOVA shows "I can't reliably assess this movement" instead of fabricating feedback. Uncertain data produces no analysis.

🌍 Individual Variation

People have different anatomies, mobility, flexibility and histories. MOVA's feedback is broad and descriptive — not prescriptive. There is no single "correct" squat.

📷 Data Privacy

All computer vision runs locally via WebAssembly. Camera feed never leaves your browser. Only session statistics (reps, duration, score) are stored in the database — no video, no images.

⚡ Explainability

Every feedback message traces to a specific measurable value — a joint angle, a position ratio or a phase detection event. MOVA never produces unexplained verdicts.
